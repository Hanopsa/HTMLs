Curves

Curves are drawn on the plane. The integral is ∫ f dz along each curve, from its start to its end.
  1. Open path → parametrize, or use an antiderivative
  2. Closed, nothing singular inside → 0
  3. Closed, 1/(z−a) → 2πi·f(a)
  4. Closed, 1/(z−a)n+1 → 2πi·f(n)(a)/n!
1 · Simple curve, open path

Parametrization

∫C f(z) dz = ∫ab f(z(t)) · z′(t) dt
Where z(t) = x(t) + i·y(t)
  • C is piecewise smooth and f is continuous on C.
  • Direction matters: reversing the path flips the sign.
  • The Calculate button uses this formula.

Antiderivative shortcut

∫C f(z) dz = F(z2) − F(z1)
  • F′ = f, and f is analytic on a region that contains C.
  • Only the end points count, the route does not.

Circle around a

z = a + r eit,  dz = i r eit dt,  0 ≤ t ≤ 2π
  • Counterclockwise for increasing t.
  • In the curve panel: x = ax + r·cos(t), y = ay + r·sin(t).

Size estimate (ML bound)

|∫C f dz| ≤ M · L
  • M = largest |f| on C, L = length of C.
  • Useful as a sanity check on a computed value.
2 · Closed curve

Cauchy–Goursat

∮C f(z) dz = 0
  • C is a simple closed curve.
  • f is analytic on C and everywhere inside it, with no singular point.
  • A singularity outside C changes nothing, the answer is still 0.
3 · Closed curve with a singularity

Cauchy integral formula

∮C f(z)
z − a dz = 2πi · f(a)
  • C is simple, closed and counterclockwise (clockwise gives −2πi·f(a)).
  • a lies strictly inside C. If a is outside, the result is 0.
  • f is analytic on and inside C.
Recipe
  • Find the bad point a, strip off the 1/(z−a) factor, evaluate what is left at a.
  • Example: ∮ ez/(z−1) dz around 1 = 2πi·e.
4 · Denominator in a power

Generalized Cauchy formula

∮C f(z)
(z − a)n+1 dz = 2πi
n! f(n)(a)
  • Same conditions as above: simple, closed, counterclockwise, a inside, f analytic on and inside C.
  • n is a whole number, one less than the power in the denominator.

Toolbox

Standard power integral

∮|z−a|=r (z − a)m dz = 2πi if m = −1, otherwise 0
  • m is any whole number, circle traversed counterclockwise.

Split into real integrals

∫ w dz = ∫ (u dx − v dy) + i ∫ (v dx + u dy)
  • w = u + i·v and dz = dx + i·dy.
  • The calculator reports these as the real and imaginary parts.

Is the field analytic?

ux = vy,   uy = −vx
  • Cauchy–Riemann equations, with continuous partial derivatives.
  • If they hold everywhere inside a closed C, the closed integral is 0.

Reading the arrows

r = √(u² + v²),  θ = atan2(v, u)
  • Each arrow points at angle θ and its length follows r.
  • Colour darkens as r grows.
